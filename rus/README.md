# Модификации прошивки для ATS-20+ (форк от diqezit)

Этот репозиторий является форком (ответвлением) оригинальной прошивки `goshante/ats20_ats_ex` и посвящен пользовательским модификациям, исправлению ошибок и добавлению новых функций. Все обсуждения, касающиеся новых версий, должны вестись здесь.

Ваши отзывы и предложения приветствуются!

Оригинальный проект можно найти здесь: [goshante/ats20_ats_ex](https://github.com/goshante/ats20_ats_ex)

---

## Ключевые модификации

Этот форк вносит несколько ключевых улучшений по сравнению с оригинальной прошивкой:

*   **Устранение щелчков звука:** Аппаратно-программная доработка, обеспечивающая чистый звук без щелчков при переключении режимов (требует небольшой физической доработки).
*   **Серия прошивок `MOD_NO_RDS`:** Полная эволюция прошивки, в которой удалена функция RDS для добавления списка избранных FM-станций, а также внесены десятки других исправлений и улучшений.

## Мод для устранения щелчков звука

Эта модификация полностью устраняет щелчки звука, которые возникают при переключении режимов или диапазонов. Она требует небольшого изменения в схеме: подключения вывода `shutdown` усилителя MD8002A к Arduino.

**Это улучшение влияет только на вывод звука через динамик**, поскольку разъем для наушников подключен до усилителя в звуковом тракте.

![Схема подключения выводов](https://github.com/user-attachments/assets/681c515e-bbb1-4213-845b-1d2d178f52b2)

#### Основные изменения:
*   **Аппаратное приглушение (Mute):** Реализовано аппаратное приглушение звука через управление выводом `shutdown` усилителя MD8002A (пин `A3`).
*   **Безопасное управление усилителем:** Добавлены функции для плавного включения и выключения динамика во время операций, вызывающих щелчки.
*   **Оптимизация памяти:** Строки с названиями полос пропускания перенесены в PROGMEM, что сэкономило ~100 байт ОЗУ и исправило зависания дисплея.
*   **Добавлен индикатор FM-стерео:** Звездочка `*` теперь появляется при обнаружении стерео пилот-тона в FM-диапазоне.
*   **Динамический RSSI:** Добавлен динамический индикатор RSSI для FM-режима.

## Серия прошивок `MOD_NO_RDS`

Это альтернативная ветка прошивки, в которой **отключена функция RDS** для реализации **списка избранных FM-станций**. Она также включает в себя множество других исправлений и улучшений. Ниже представлен полный список изменений.

### `MOD_NO_RDS` (Начальная версия)

Эта версия добавляет возможность сохранять ваши любимые FM-станции.

#### Управление
*   **Открыть меню избранного:** Короткое нажатие кнопки **MODE** в режиме FM.
*   **Навигация по списку:** Вращение энкодера.
*   **Выбрать станцию:** Короткое нажатие энкодера.
*   **Удалить станцию:** Нажатие кнопки **BW**.
*   **Выйти из меню:** Нажатие **BAND UP/DOWN** или **MODE**.
*   **Сохранить текущую станцию:** Длинное нажатие кнопки **MODE**.

#### Исправления и дополнения
*   **Исправлен поиск в FM:** Устранены конфликты команд и неверный шаг поиска, которые вызывали пропадание звука ([Issue #46](https://github.com/goshante/ats20_ats_ex/issues/46)).
*   **Исправлена сетка частот AM:** Выровнена сетка с шагом 9 кГц для корректной работы ([Issue #44](https://github.com/goshante/ats20_ats_ex/issues/44)).
*   **Экономия памяти:** Упрощен расчет заряда батареи и удалены избыточные функции для освобождения Flash-памяти.

### `MOD_NO_RDS v2`

*   **(Переработано) Управление шагом перестройки:** Созданы раздельные настройки шага для AM/SSB, так что изменения в одном режиме не влияют на другой.
*   **(Улучшено) Отображение уровня заряда батареи:** Используется формула интерполяции для более точного и плавного отображения процента заряда.
*   **(Исправлено) Режим приема CW:** Введено автоматическое смещение BFO (+/- 500 Гц) для более интуитивной настройки в CW ([Issue #15](https://github.com/goshante/ats20_ats_ex/issues/15)).
*   **(Новое) Умное определение SW-диапазонов:** Отображаются названия любительских/вещательных диапазонов (например, "40m", "20m") вместо общего "SW".

### `MOD_NO_RDS v3`

**(!) Внимание:** Эта версия являлась результатом крупного рефакторинга и должна считаться экспериментальной.

*   **(Изменено) Контекстно-зависимые настройки:** Шаг перестройки, полоса пропускания и усиление теперь сохраняются независимо для каждого режима (AM/SSB/FM) и диапазона.
*   **(Улучшено) Система мониторинга батареи:** Переработана с использованием IIR-фильтра и гистерезиса для стабильного отображения без мерцаний.
*   **(Исправлено) Надежность EEPROM:** Реализована система версий для автоматического сброса настроек после обновления прошивки, что предотвращает зависания.
*   **(Добавлено) Анимированный индикатор загрузки** на стартовом экране.

### `MOD_NO_RDS v3.1`

*   **(Переработано) Основная функция `loop()`:** Структура основного цикла программы переработана для повышения стабильности и упрощения поддержки.
*   **(Исправлено) Инвертированная логика BFO в режиме CW:** Исправлена ошибка, из-за которой менялись местами боковые полосы LSB/USB.
*   **(Улучшено) Расширен диапазон калибровки BFO:** Диапазон увеличен до **+/- 2.5 кГц** для компенсации значительного ухода частоты кварца.
*   **(Исправлено) Предотвращение выхода за пределы BFO:** Внутренний диапазон BFO был ограничен, чтобы избежать превышения аппаратных лимитов чипа Si4732.

### `MOD_NO_RDS v3.2`

*   **(Улучшено) "Привязка к сетке" для AM/FM:** Первый поворот энкодера теперь автоматически выравнивает частоту по ближайшей точке сетки.
*   **(Переработано) Управление яркостью дисплея:** Заменено на простую шкалу **от 1 до 10** с кривой для визуально линейного изменения яркости.
*   **(Новое) Настраиваемый конденсатор антенны:** В меню добавлена опция для включения/отключения входного конденсатора для оптимизации работы с разными антеннами.
*   **(Исправлено) Система аттенюатора:** Аттенюатор переведен в ручной режим для устранения цифрового шума от I2C, возникавшего в режиме AUTO AGC.

### `MOD_NO_RDS v3.3`

*   **(Оптимизировано) Уменьшение размера прошивки:** Переработаны множественные функции, что уменьшило итоговый размер прошивки более чем на 200 байт.
*   **(Исправлено) Расчет BFO:** Исправлена ошибка, приводившая к неверному отображению частоты при отрицательных значениях BFO.
*   **(Исправлено) Управление полосой пропускания FM:** Направление вращения энкодера теперь верное (по часовой стрелке — увеличивает полосу).
*   **(Изменено) Режим ATT по умолчанию:** Режим AUTO для аттенюатора снова установлен по умолчанию.
*   **(Улучшено) Структура кода:** Логика обработки кнопок была переработана и разбита на более мелкие функции для упрощения отладки. Функциональность для пользователя осталась прежней.
